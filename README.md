# Interactive Birthday Card 🎂

A single-page, no-build interactive birthday greeting. Vanilla HTML + CSS + JS,
inline SVG artwork, spring animations, confetti and a working music player.

## Run it

Just open `index.html` in a browser. No server, no install, no build step.
(If you prefer a server: `python3 -m http.server` then visit `localhost:8000`.)

## Files

```
index.html          markup — inline SVG for the cake/vinyl/flip-card, <img> for the rest
css/style.css       every style, numbered by section
js/app.js           screen machine, confetti, typewriter, audio, flip card
assets/images/      the 6 cropped, background-removed PNGs used as <img> sources
assets/audio/       put your own song here (optional)
build.py            bundles css+js+images into dist/index.html (one file)
dist/index.html     generated single-file build — good for sharing/WhatsApp
```

## Artwork

Six pieces of artwork are real images (background removed, cropped, saved as
transparent PNGs) rather than drawn SVG, living in `assets/images/`:

| File | Used on |
|---|---|
| `bigeye.png` | "Please accept the gift" screen |
| `crying.png` | "Why did you click no!" screen |
| `envelope.png` | Gift hub card + the letter screen |
| `bouquet.png` | Gift hub card + the flowers screen |
| `giftbox.png` | Gift hub card |
| `shy.png` | Flowers screen (left character) |
| `special-photo.jpg` | Back of the flip card — the big reveal at the end |

Everything else — the cake, the vinyl record, the flip-card front/back, and
all the corner decoration (ribbons, disco ball, hearts, sparkle, cocktail,
camera) — stays hand-drawn inline SVG, so it scales perfectly at any size
and recolors instantly if you tweak the CSS variables.

To swap any of the six photos for your own: replace the file in
`assets/images/` (keep the same filename) and re-run `python3 build.py` if
you also want an updated single-file version.

## The flow

1. Cake — blow the candles, confetti, then Next
2. Please accept the gift — Yes / No
3. No → the crying screen → Try again
4. Choose your gifts — envelope / flowers / gift box
5. Letter — slides out of the envelope and types itself
6. Flowers — bouquet, blushing doodle, stickers
7. Music + card — vinyl spins while playing, OPEN flips the card, confetti, farewell toast

## Music

No audio file ships with this repo. The player works out of the box with a short
original piano loop generated by the Web Audio API.

To use a real song **you own a copy of**:

1. Put the file at `assets/audio/song.mp3`
2. In `js/app.js` set `var SONG = 'assets/audio/song.mp3';`

Or click **use your own mp3** in the player to load a file from your computer at
runtime (nothing is uploaded — it stays in the browser).

## Customising

- Letter text: `LETTER` at the top of section 6 in `js/app.js`
- Colours: the `:root` variables at the top of `css/style.css`
- Track name shown in the player: the `.meta` block in `index.html`

## Deploy to GitHub Pages

```bash
git init
git add .
git commit -m "birthday card"
git branch -M main
git remote add origin https://github.com/<you>/<repo>.git
git push -u origin main
```

Then in the repo: **Settings → Pages → Branch: main / root**. Your link will be
`https://<you>.github.io/<repo>/`.
